# Game Integration Docs

Load these docs when they match the game task:

- `packages/game-platform/`: Game Platform SDK source and types.
- `packages/games/`: individual game packages (breakout, checkers, chess, memory, platformer, snake, tetris, tower-defense).
- `packages/pointclick-engine/`: point-and-click adventure engine.
- `docs/new-games-development-plan.md`: game development roadmap and conventions.
- `docs/GAME_ENGINE_STRATEGY.md`: game engine architecture decisions.
- `docs/QUICK_START.md`: setup and development quick start.
- `lib/feature-flags.ts`: game-related feature flag definitions.
